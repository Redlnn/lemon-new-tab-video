# Lemon / 每一次打开，都更像你

40 seconds. 3840 × 2160. 60 fps. Chinese kinetic typography, no voiceover.

## Visual direction

Dark product film. Large warm-white typography, lemon-yellow accents, fine grain, restrained specular rims, abstract flowing wallpaper. Fast typographic cuts alternate with long eased camera moves. Reconstructed UI follows actual extension features; spatial separation is editorial motion design.

## Palette

- Canvas #08090b
- White #f4f4ef
- Lemon #f5c842
- Graphite #25262b
- Muted #a5a7ab

## Type

HarmonyOS Sans SC variable font for Chinese and Latin; verified wght axis 40–900. Load the unmodified local font from public/HarmonyOS_Sans_SC.ttf. Display weight 800, regular UI weight 400. No Chinese full stops in display headlines.

## Motion

Heavy deceleration: cubic-bezier(.16,1,.3,1). Perspective 1800px, readable UI at rest. Match cuts between search field and Dock. Three personalization beats. Quiet creator statement before final logo.

## Avoid

Tiny feature lists, excessive glow, continuous spinning, fabricated speed statistics, unnecessary browser chrome, unreadable rotated text.
